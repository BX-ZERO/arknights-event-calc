# 明日方舟活动代币计算器

当前版本：**1.0.1**

算清楚一个活动还要刷多少把、多少理智。

勾上想换的东西，填上已经换了多少，页面直接给出「还差多少代币、还要刷多少把」。往期限定的两套时装、国度信物的分档、无限库存区都单独处理过，不会算错。

## 怎么用

1. 打开 `index.html`（或发布的网址）。
2. 在商品表里勾选「要换」的东西，填「数量」和「已换」。
3. 上方「当前持有代币」填你手上的代币数。
4. 「一次性代币来源」里勾掉已经拿过的任务和关卡首通。
5. 看顶部四个格子：勾选总价、其中已换、还差代币、还需刷几把。

点「同步最新数据」可以去网上取最新的活动数据。

勾选和填的数字会记在浏览器里，关掉页面下次打开还在，不用重新填。想从头来一遍就点「重置」，会把勾选、数量、已换、持有代币、关卡选择全部恢复成初始状态。换活动时旧记录自动失效，因为每个活动分开存。

键盘也能用：分组标题可以用 Tab 聚焦，回车或空格展开收起。想打印的话直接 Ctrl+P，会自动去掉按钮和横幅，只留表格。

## 给使用者的两条路

页面底部写了「两种用法」，对应两种人：

| 用法 | 适合谁 | 需要什么 |
|---|---|---|
| 直接用网页 | 大部分玩家 | 浏览器。数据由作者更新，点右上角「同步最新数据」即可 |
| 下载离线包 | 想自己抓数据、或网站打不开 | Python。解压后双击 `启动计算器.bat`，跑 `更新活动数据.py` 自己更新 |

离线包的下载链接指向 `https://github.com/<用户名>/<仓库名>/archive/refs/heads/main.zip`，由生成脚本按 `仓库配置.txt` 自动拼；没配置仓库时链接是空的，不会误导人。

所以仓库里的文件要传全 —— 不只是网页那三个，脚本也要在，不然下载下来没法更新。

## 数据来源

所有活动、商店、关卡数据来自 [PRTS Wiki](https://prts.wiki/)，由 `更新活动数据.py` 抓取。

- 商店价格、里程碑奖励、关卡掉落都是 wiki 上的原始数据。
- 关卡首通奖励与任务奖励分开统计，不会和刷取收益混在一起。
- 图上标的「未开放」是还没解锁的关卡，首通代币数 wiki 上暂时没有，用问号占位。

## 换新活动

```
更新活动数据.py "新活动名"
```

跑完会重新生成 `index.html`、`活动代币计算器.html`、`活动数据.json`、`活动数据.js`。把 `index.html` 和 `活动数据.js` 传到仓库，访客点一下按钮或刷新页面就能拿到新数据。

## 部署到 GitHub Pages（分享用）

1. 建一个 Public 仓库，比如 `arknights-event-calc`。
2. 把这几个文件传上去：`index.html`、`活动数据.js`、`og.jpg`、`icon.png`。
3. 打开 `仓库配置.txt`，把第一行注释换成 `你的用户名/仓库名`，重跑一次 `更新活动数据.py`，再上传新的 `index.html`。这一步是为了让页面能远程拉数据，也让分享卡片用上绝对地址。
4. Settings → Pages → Deploy from a branch → `main` / `(root)`，等一两分钟。
5. 访问 `https://<用户名>.github.io/arknights-event-calc/`。

`og.jpg` 是分享卡片图（1200×630）。丢到 QQ、微信、Discord 里会显示这张图和标题描述，别漏传，也别删。

`icon.png` 是 180×180 的图标，给 Safari 和添加到主屏用；Chrome、Edge 直接读页面里内联的 SVG，不依赖这个文件。

分享卡片的标题和描述写在 `index.html` 头部的 `og:` 标签里，想改文案直接改那几行。图片地址由 `仓库配置.txt` 自动拼成绝对地址，`og:image` 用相对路径的话大部分平台不会显示。

## 本地运行（可选）

不想用网页版时，进入 `离线工具/` 双击 `启动计算器.bat`，会起一个本地服务并打开页面。这时点页面上的「同步最新数据」，是由本机的 Python 直接去 wiki 抓，比线上稳。

需要 Python 3。第一次装的时候记得勾上「Add Python to PATH」，否则 bat 找不到解释器。
