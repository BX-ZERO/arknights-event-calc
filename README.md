# 明日方舟活动代币计算器

当前版本：**1.0.1**

网上没找到活动代币计算器，让大肥鱼搓了一个。除文案外AI生成率100%，本人非计算机专业，欢迎指导及提交BUG。

发布网址：**https://bx-zero.github.io/arknights-event-calc/**

## 计算器使用方式

1. 打开项目仓库内`index.html`（或发布的网址）。
2. 在商品表里左侧勾选「要换」的东西，右侧填「数量」和「已换」。
3. 上方「当前持有代币」填写手中的代币数。
4. 「一次性代币来源」里勾选已经拿过的任务和关卡首通。
5. 顶部四个格子自动计算：勾选总价、其中已换、还差代币、还需刷几把。

点「同步最新数据」可以去网上取最新的活动数据。

勾选和已经填写的数字会保存在浏览器里，不用重复重新填。想清空就点击「重置」，会把勾选、数量、已换、持有代币、关卡选择全部恢复成初始状态。活动更换时旧记录自动失效。

## 自己更新数据

双击文件夹里的`更新数据.bat` 会弹出一个菜单：

1. **默认（最新活动数据）** —— 更新到最新数据。
2. **过往活动预览** —— 按年份列出已结束的活动，选一个更新。

选完等待进度条加载，联网下载wiki数据，本地index.html、活动数据.json、活动数据.js 三个文件会更新

### 需要什么

电脑装了 Python 3（[下载地址](https://www.python.org/downloads/)），安装时务必勾上 **Add Python to PATH**，否则 bat 找不到解释器。

如果双击 bat 弹「无法验证发布者」，点「更多信息 → 仍要运行」，或者右键 → 属性 → 勾选「解除锁定」。


## 数据来源

所有活动、商店、关卡数据来自 [PRTS Wiki](https://prts.wiki/)，由 `更新活动数据.py` 抓取。

- 商店价格、里程碑奖励、关卡掉落为 wiki 上的原始数据。
- 关卡首通奖励与任务奖励分开统计，不会和刷取收益混在一起。
- 图上标的「未开放」是还没解锁的关卡，首通代币数 wiki 上暂时没有，用问号占位。
