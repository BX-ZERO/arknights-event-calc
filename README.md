# 明日方舟活动代币计算器

当前版本：**1.0.1**

网上没找到活动代币计算器，让大肥鱼搓了一个。除文案外AI生成率100%，本人非计算机专业，欢迎指导及提交BUG。

发布网址：**https://bx-zero.github.io/arknights-event-calc/**

## 计算器使用方式

1. 打开项目仓库内`index.html`（或发布的网址）。
2. 在商品表里左侧勾选「要换」的东西，右侧填「数量」和「已换」。
3. 上方「当前持有代币」填写手中的代币数。
4. 「一次性代币来源」里勾选已经拿过的任务和关卡首通。
5. 顶部四个格子自动计算：勾选总价、其中已换、还差代币、还需刷几把。

点「同步最新数据」可以去网上取最新的活动数据。

勾选和已经填写的数字会保存在浏览器里，不用重复重新填。想清空就点击「重置」，会把勾选、数量、已换、持有代币、关卡选择全部恢复成初始状态。活动更换时旧记录自动失效.


## 给使用者的两个使用方式

页面底部写了「两种用法」，对应两种人：

| 用法 | 适合谁 | 需要什么 |
|---|---|---|
| 直接用网页 | 大部分玩家 | 浏览器。数据由作者更新，点右上角「同步最新数据」即可 |
| 下载离线包 | 想自己抓数据、或网站打不开 | Python。解压后双击 `启动计算器.bat`，跑 `更新活动数据.py` 自己更新 |

离线包的下载链接指向 `https://github.com/<用户名>/<仓库名>/archive/refs/heads/main.zip`，由生成脚本按 `仓库配置.txt` 自动拼；没配置仓库时链接是空的。

所以仓库里的文件要下载全

## 数据来源

所有活动、商店、关卡数据来自 [PRTS Wiki](https://prts.wiki/)，由 `更新活动数据.py` 抓取。

- 商店价格、里程碑奖励、关卡掉落为 wiki 上的原始数据。
- 关卡首通奖励与任务奖励分开统计，不会和刷取收益混在一起。
- 图上标的「未开放」是还没解锁的关卡，首通代币数 wiki 上暂时没有，用问号占位。

## 新活动

```
更新活动数据.py "新活动名"
```

跑完会重新生成 `index.html`、`活动代币计算器.html`、`活动数据.json`、`活动数据.js`。

## 本地运行（可选）

不想用网页版时，进入 `离线工具/` 双击 `启动计算器.bat`，会起一个本地服务并打开页面。这时点页面上的「同步最新数据」，是由本机的 Python 直接去 wiki 抓，比线上稳。

需要 Python 3。第一次装的时候记得勾上「Add Python to PATH」，否则 bat 找不到解释器。
